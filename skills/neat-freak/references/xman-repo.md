# 在 x-mansion 母仓里同步

当前项目是 x-mansion 母仓时读。别的项目用不到这份。

## 事实源在哪

```text
Skill 本体：skills/<name>/SKILL.md
Agent 本体：agents/<name>.md（扁平文件）；伴随文件在 agents/<name>/
上下文规范：context/conventions.md、context/schema/*.md、context/templates/*.md
治理登记：governance/skills-registry.csv、governance/sources/*.json
入口文档：README.md、QUICKSTART.md、CLAUDE.md、AGENTS.md
```

`team/skills/`、`plugins/*/` 是软链视图；平台安装目录（`.claude/`、`.codex/`、`.cursor/`、`.gemini/`）里的 skill 和 agent 是软链或生成产物。Codex 的 agent 落地成 `.codex/agents/<name>.toml`，由 `agents/<name>.md` 生成，首行带 `Generated by` 标记。这些条目过期时改源文件再重新安装，就地编辑会在下次安装时被覆盖。

## 改了什么 → 要查哪里

| 改了什么 | 要查的地方 |
|---|---|
| 新增、改名或删除 skill | `governance/skills-registry.csv`（删除留墓碑行）、`skills/ask-xman/SKILL.md`、`evals/budgets.json`、README 和 QUICKSTART 的清单、引用它的其他 skill 和 agent |
| 新增、改名或删除 agent | `agents/README.md`、`governance/skills-registry.csv`、README 和 QUICKSTART |
| 路径约定 | `context/conventions.md`、`context/naming-contract.json`、引用该路径的 skill 和 agent |
| 安装方式或 CLI | `xman` 帮助文本、README、QUICKSTART、规则文件 |
| 流程编排 | `agents/xman-flow.md`、`agents/xman-flow/references/*.md`、README 里的流程说明 |

改完运行 `./xman validate --fix`、`./xman plugin build` 和 `python3 -B -m unittest discover -s tests`。
