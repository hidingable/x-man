# 人工执行向导

把已经核实的接入或配置步骤写成可检查、可重复执行的脚本，让人掌握登录、凭据输入和实际变更。默认交付脚本和说明；不替用户运行生成脚本里的真实系统操作，不默认提交代码。

## 先核对事实

- 读取目标项目的真实配置、已有脚本和官方操作说明，确定环境、账户、资源标识、配置格式与成功信号。控制台入口只写已核实的 URL 和路线；读不到的页面明确留待核实，不编造菜单。
- 区分人工动作与脚本动作，写清每一步会修改的文件或外部资源、所需权限及失败后的恢复方法。只有影响步骤正确性的缺口才需要澄清。
- 凭据由执行者当场输入；不让用户把密钥贴进对话，不把密钥写入生成源码、示例、命令行参数、日志或完成摘要。

## 生成脚本

从 `assets/wizard-template.sh` 复制公共函数，只实现本次需要的回调和 `wizard_main`。模板面向 macOS 自带 Bash 3.2 和 Python 3，也可用于 Linux；不用关联数组、`readarray` 等较新 Bash 特性。

- `wizard_init "$@"` 解析 `--dry-run`。每个步骤用 `run_stage 名称 探测函数 执行函数 验证函数`：探测返回 0 表示已完成、1 表示需执行，大于 1 表示检查失败；执行前默认拒绝，执行后必须验证。探测中的文件/API 读取须显式处理失败并返回大于 1 的状态；只有已核实的“尚未配置”才返回 1，不能直接沿用外部命令可能代表错误的退出码 1。
- 回调在独立的严格 Bash 子进程中执行，中间命令失败会终止该回调。函数定义自动传入，跨阶段参数需显式 `export`；每步产生的持久状态通过真实文件或服务重新读取，不能依赖回调内的新变量传回父进程。探测和验证应只读，并根据实际状态返回。
- `ask 变量名 提示`、`ask_secret 变量名 提示` 将输入写入指定变量，EOF 返回失败；密钥用后 `unset`。只在已确认执行的回调中取密钥，通过环境变量或标准输入交给工具，并关闭或脱敏工具自身的响应输出。不得重新打开 xtrace。
- `open_url URL` 只接受明确的 HTTP(S) 地址；URL 不含凭据。只在执行回调中使用，执行者在浏览器完成登录等人工动作后，再由脚本读取所需输入或验证结果。
- `write_env 文件 键 值变量名` 从变量取值，不把值放进进程参数。按单行 shell 赋值格式写入，保留其他内容，重复执行不重复追加，原子写入并设为 0600；最终文件为软链、输入含换行或读取失败时拒绝；已有文件含跨行引号、反斜杠续行或 shell 控制语法（如命令替换、heredoc）时，也在匹配键前拒绝写入并保留原文件，不执行配置来解析它。文件父目录须已存在。目标工具使用其他 dotenv 解析规则时，先按真实契约调整写入方式并验证，不假定所有 `.env` 解析器兼容；不执行不可信配置文件来读取它。
- dry-run 只列出步骤，不执行探测、读取密钥、打开浏览器或写文件；未确认的步骤不执行。需要 `gh secret` 等外部写入时，只有目标仓库/环境已明确且本次确有需要才加入，密钥经 stdin 传入；不扩展成通用基础设施管理器。

`wizard_main` 内按真实依赖顺序调用步骤。没有填完步骤的模板会报错退出；保留这个拒绝行为直到脚本可交付，不用空操作或固定返回成功替代验证。

## 验证与交付

先做 `bash -n`，再在临时目录中用伪命令和受控输入运行：dry-run 无副作用、默认拒绝和 EOF、重复执行、密钥不出现在输出、探测/读取/执行/验证失败。仅静态语法通过不算行为验证；没有实际执行的外部步骤必须标为未验证。

按 `.ai-configs/conventions.md`〈主产物与伴随文件〉保存说明与同名 `.sh`，默认使用 `doc` 类型；已指定目标文件时沿用该位置。交付说明列出依赖、执行命令、每步副作用、配置格式、已验证结果和仍需人工完成的事项，摘要不包含凭据。
