# 措辞替换库

---

## 一、模糊词 → 确定表达

| 别写 | 写成 |
|---|---|
| 大概完成 80% | 已完成 8 项中的 6 项，剩余 2 项于 X 日前交付 |
| 可能是因为…… | 归因未完成，核查结论 X 日前补齐；待核方向为…… |
| 猜测 / 初步考虑 / 初步评估 | 已定位（有数据支撑时）／ 归因未完成 + 交付时间（无数据时） |
| 差不多可以上线 | 功能已完成，回归测试剩 2 项，X 日上线 |
| 争取月底完成 | X 月 X 日完成；若 A 条件不满足则顺延至 X 日 |
| 后续考虑优化 | X 季度完成…… |
| 待预研确定 | 预研于 X 日前出结论，届时决定做或不做 |
| 有一定影响 | 影响 X 个区域、X 家客户、金额约 X 万 |
| 基本完成 | 完成 X/Y；未完成部分为…… |

**核心**：不确定留在自己肚子里，站到老板面前时要是确定的。确实不确定的，把"不确定"本身写成确定的——未完成什么、什么时候给。

## 二、形容词 → 数据句式

| 别写 | 写成 |
|---|---|
| 客户很满意 | 续费率从 80% 升至 92% |
| 使用量有较大提升 | 使用量 276w，同比增长 47.98% |
| 咨询量增长很多 | 咨询量 3120 次，为去年的 2.94 倍（去年 1062 次） |
| 成功率达标 | 取数 92.5%、公示 88.47%，均高于 80% 达标线 |
| 效果不错 | ——（这句没有任何信息，删掉，换成具体指标） |
| 反馈普遍较好 | 易用度调查 X 份，好评率 X%，TOP3 好评点为…… |

**倍数与百分比必须复核**："增长了 3 倍"的分母是原值的 4 倍。3120/1062 是 2.94 倍、增幅 194%，不是增长 3 倍。这类错误一旦进了老板的口头引用，纠正成本极高。

## 三、技术语言 → 老板语言

老板关心五件事：目标、进度、风险、资源、竞品。不在这五项里的，翻译或删掉。

| 别写 | 写成 |
|---|---|
| 优化了代码 / 重构了模块 | 响应时间从 3 秒降至 0.5 秒，投诉率下降 40% |
| 增加了自动重试机制 | 公示成功率从 X% 升至 Y%，减少人工返工约 X 次/月 |
| 对接了总局接口 | 用户手工录入环节减少 X 步，覆盖 X 个区域 |
| 支持批量取数 | 单机构处理 100 户的耗时从 X 小时降至 Y 分钟 |
| 做了埋点和监控 | 线上问题从"大区反馈后发现"提前到"发生当天告警" |
| 该功能有竞品也有 | 同区域主要竞品 X 已具备该能力，且在本区域有 X 个网点，构成实际影响 |

## 四、第一人称 → 无人称

书面稿正文不出现"我""我们""咱们""笔者"。判断本身就带署名。

| 别写 | 写成 |
|---|---|
| 我认为增长引擎已经换挡 | 增长引擎已经换挡 |
| 我建议尽快推进 | 建议 X 年 Q1 启动 |
| 我们做了三件事 | 本期完成三件事 |
| 我会在 9 月底前补上测算 | 收入测算于 9 月底前补齐 |
| 我的判断是 A 方案更优 | 判断：A 方案更优，依据如下 |
| 我需要您支持 | 待决事项 / 需要拍板的三件事 |
| 我们遇到了困难 | 当前卡点：XXX（附处置建议） |

**例外**：口头发言脚本、IM 短消息可保留"我"。

## 五、姿态：不卑不亢

| 别写 | 写成 |
|---|---|
| 打扰您了 | ——（删除） |
| 还请多多指正 / 如有不妥请批评 | ——（删除） |
| 恳请领导支持 | 待决事项：…… |
| 必须立刻 / 只能这么做 | 建议…… ；若不采纳，则…… |
| 这个我们也没办法 | 当前受限于…… ，可选方案有二：…… |

## 六、提问层 → 决策层（句式改造）

这一组最关键。见到左栏句式一律改造。

| 别写 | 写成 |
|---|---|
| 是否还要扩展新地区？ | 建议：新地区整体降级为条件触发，触发条件为……；候选收敛至 X |
| 要做的话做哪些呢？ | 建议：本期仅做 X，按 A 标准排序取前 N 项；其余不启动 |
| 这块要不要投入？ | 建议投入 / 不投入，理由：……；若不采纳，后果为…… |
| 大家看看怎么办 | 建议方案 A（附代价与收益）；备选 B；需拍板 |
| 后续再讨论 | 于 X 日前单独会议闭环，产出为…… |

需要老板拍板的事，写成"建议 A，理由 B，需确认"，不写成开放式问句。
