# 场景骨架与坑

黄金结构（结论 → 证据 → 判断 → 建议动作 → 待决事项）是底座，不同场景对它有增删。写之前读对应那一节。

**目录**
1. 周报 / 月报
2. 项目节点与要资源
3. 坏消息与危机
4. 述职与经营分析会
5. 产研年度规划与需求评审

---

## 1. 周报 / 月报

**增**：与上期的差分。老板记不住上周的数，要替他做对比。
**删**：背景介绍、项目意义。周期性汇报不需要每次重讲一遍项目是什么。

骨架：本期结论一句 → 关键指标与上期差分 → 异常项及归因 → 下期动作 → 需要支持的事（没有就写"暂无"）。

**坑**：
- 写成流水账。做了什么不重要，指标变了多少才重要。
- 报喜不报忧，攒到季度末一起爆。周报的价值就在于早暴露。
- 每周都写"正常推进中"。连续三周无差分，说明这个指标不该每周报。

---

## 2. 项目节点与要资源

**增**：不给资源的后果推演。要资源的稿子，核心不是"我需要什么"，是"不给会怎样"。
**增**：资源用途的颗粒度。给几个人、干什么、什么时候能看到产出。

骨架：结论（要什么、多少、什么时候要）→ 现状与缺口的量化 → 不给资源的后果推演 → 资源投入后的预期产出 → 待决事项。

**坑**：
- 把"要资源"藏在稿子末尾。老板读到一半才发现是来要人的，会觉得前面都是铺垫。要资源就在第一句说。
- 只说缺人不说缺多少。"人手紧张"是抱怨，"B 环节需增 2 人，否则 11 月节点顺延三周"是请求。
- 不敢要够。咽回去的部分不会自己长出来。

---

## 3. 坏消息与危机

**增**：时间线。什么时候发生、什么时候发现、什么时候上报——这三个时间的间隔本身就是信息。
**增**：影响范围的边界。已影响什么、可能扩散到什么、确定不影响什么。

骨架：坏消息一句话 → 时间线 → 影响范围 → 已采取的处置 → 待决事项与需要的支持。

**坑**：
- 铺垫。"最近我们遇到一些挑战"这种开场，老板会预设更坏的结果。
- 只报警不救火。坏消息必须凑齐三元组：坏消息 → 事实（带数字）→ 处置建议。缺处置的不许写进稿子。
- 责任归因写在处置前面。先说怎么办，追责的部分老板会自己问。

---

## 4. 述职与经营分析会

**增**：全周期视角。不是本季度做了什么，是这条线在整个生命周期里走到了哪。
**增**：明年的取舍表态。述职不表态，等于把规划扔回去。

骨架：首页决策区（结论、关键数据表、坏消息表、待拍板事项）→ 分章节证据区 → 附录区。超过 8 页必须分层。

**坑**：
- 首页遮住还能读出结论，说明结论没提上来。
- 数据堆砌，每张图都放，但没有一句判断。每章开头先写一句判断，后面才是明细。
- 把功劳写满、把问题写没。老板知道没有零问题的业务线，全是好消息反而降低可信度。

---

## 5. 产研年度规划与需求评审

**这类稿子最容易掉进提问层。** 因为规划天然面对一堆候选项，写的人下意识把选择题交出去——"是否还要扩展新地区""要做的话做哪些"。这不是谦虚，是把年度决策原样退回给老板。见到问句一律改写成带依据的建议。

**增：竞品对照列。** 这是这类场景与其他场景最大的差别。候选项表必须有"同区域主要竞品是否具备"一列，没有这列，整张表的准入依据就只有内部数据，老板无法判断。

**增：做/不做双栏。** 不要只列"计划做的"。明确写出本期不做的项及理由，比只写要做的更能体现判断。

**增：优先级排序及其依据。** 列了 N 项就要排出 1 到 N，并说明排序原则（例如成本影响优先于功能补齐）。无序清单等于没排。

**减：功能明细。** 具体功能点整体下沉到附录或保持原位，决策相关内容提到前面。

骨架：

```
结论（本期资源投向的一句话取舍表态）
支撑依据（3 条，其中至少 1 条是竞品或成本口径）
风险与处置（坏消息三元组表）
候选项决策表  ← 列：项目 / 决策(做·缓做·不做) / 内部依据 / 竞品是否具备 / 排期
优先级排序及排序原则
待决事项（需拍板的，每条附建议方案）
待补数据与待确认判断
```

**坑**：

- **无竞品数据**。全文准入依据只有内部占比或使用量，这是这类稿子最常见也最致命的洞。判断标准见 `laoban-panju.md` 判据 1。
- **成本项缺席**。规划里只有新功能，没有已上线功能带来的咨询量、服务工时等刚性成本的治理动作。成本能折算成钱的，优先级高于 0→1。见判据 3。
- **需求来源未分层**。把"大区反馈""易用度调查满意度低"直接当作排期依据。一线声音是线索不是依据，见判据 5。
- **推测性归因**。数据异动写"猜测是因为……"。改词没用，要么补现场核查，要么明写归因未完成加交付时间。见判据 2。
- **年度口径混乱**。本年度报告里混入上年度上线项，或章节标题的年度与表内时间不符。这类矛盾自己发现不了，只能逐条比对。
- **空承诺**。"后续考虑优化""待预研确定"没有时间点和责任人。全部列进待补清单，或补上时间点。

**成稿检验**：把候选项决策表里的"决策"列遮住，剩下的信息够不够让老板自己填出来？够，说明依据写足了；不够，说明你是在让他凭感觉拍板。
