# 共享产物的写入责任

> 原为 conventions.md 的同名小节。编排多个阶段或子代理更新同一份主产物时读取。

同一需求的产品交互设计与技术架构可以共用 `design` 主产物。调用前明确负责内容和唯一整合者：`design` 负责产品交互，项目已有技术设计流程负责技术契约；它们的合法输出类型不代表各自有权替换整份文件。

- 串行更新先读完整现役文档，只修改本次负责内容，保留另一部分、已确认决定和有效引用；没有这一部分时新增明确标题，重复执行更新原部分。
- 并行子代理返回自己负责的章节或明确指定的附属稿，由整合者合并后保存。指派同一主文件给多个直接写入者属于派发冲突，应先调整责任范围。
- 整合者核对两部分是否都覆盖本次要求、是否相互矛盾、原有约束和非负责内容是否保留；材料来源和待定事项随内容保留。业务或公共契约仍未决时按授权规则处理。

这项规则同样适用于多个阶段更新其他同一主产物。原有文档结构已清楚时沿用结构；正文被删、同一章节被重复追加或一方内容被另一方替换，都不能凭路径校验通过声称交接完成。
